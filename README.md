# مرحبًا! 👋 أنا مهندس برمجيات

أنا مهندس برمجيات أتمتع بخبرة تزيد عن 14 عامًا (منذ عام 2010) في تصميم وبناء وصيانة أنظمة برمجية موثوقة. لدي اهتمام قوي ببنية الأنظمة، وإدارة خوادم لينكس، والبنية التحتية ذاتية الاستضافة (Self-Hosted)، واستكشاف نماذج الذكاء الاصطناعي (AI) المحلية.

## 🛠️ ما أفعله
* **بنية الأنظمة وتطويرها:** تصميم بنية قواعد البيانات، والواجهة الخلفية (Backend)، وواجهة/تجربة المستخدم (UI/UX) للتطبيقات المتوسطة والكبيرة.
* **البنية التحتية والاستضافة الذاتية:** إدارة الخوادم المحلية، والمحاكاة الافتراضية، والحاويات لتقليل الاعتماد على الخدمات السحابية للجهات الخارجية.
* **البيانات والذكاء الاصطناعي:** بناء خطوط أنابيب لجمع البيانات (Data Crawling) ودمج نماذج الذكاء الاصطناعي لتحليل المشاعر والأتمتة الذكية.
* **الأمن وإدارة الخوادم:** إدارة نظام أسماء النطاقات (DNS)، وإجراء المسح الأمني، وتحسين أداء الخوادم.

## 🚀 أبرز المشاريع
فيما يلي بعض الأنظمة والتطبيقات التي قمت بتطويرها:

* **نظام إدارة الحملات وصناع المحتوى الرقمي**
    منصة شاملة مصممة للوكالات الرقمية. يسهل هذا النظام إدارة صناع المحتوى، وتتبع الحملات، وقياس الأداء في الوقت الفعلي.

* **منصة التجارة الإلكترونية والمجتمع الفني**
    تطبيق ويب وهاتف محمول يربط بين الفنانين وهواة الجمع. تشمل الميزات الرئيسية إدارة مخزون الأعمال الفنية، ونظام معاملات التجارة الإلكترونية، وعرض معارض الفنانين، وإدارة الفعاليات الفنية.

* **منصة استخبارات وسائل التواصل الاجتماعي وتحليل المشاعر**
    تطبيق يستخدم جمع البيانات والذكاء الاصطناعي لتحليل المشاعر العامة عبر مختلف المنصات الاجتماعية. يولد هذا النظام مقاييس وتوصيات قابلة للتنفيذ لاستراتيجيات الأعمال.

* **خدمة واجهة برمجة تطبيقات (API) للمراسلة الفورية ذاتية الاستضافة**
    تطوير وتكوين خدمة رسائل فورية آلية باستخدام بيئة معزولة (حاويات) على شبكة محلية لتلبية الاحتياجات التشغيلية للأعمال بشكل سريع وآمن.

## 💡 الاهتمامات والاستكشاف
خارج كتابة التعليمات البرمجية، أقضي وقتي في:
* دراسة الاستراتيجية والاقتصاد والمالية والفلسفة.
* تجميع وتحسين الأجهزة (Hardware) لاحتياجات المعامل المنزلية (Homelab)، وتطوير الذكاء الاصطناعي، والحوسبة عالية الأداء.
* دراسة آليات الألعاب والاستراتيجيات التنافسية.
